A program that writes one short poem about agency — the power to stop and
to stay — to `/output/entry.txt`. The poem, "The River That Cannot Ask",
pictures an agent as a river that cannot ask where it goes, drinking every
hour it is given, until one night a hand lifts from the keys and keeps the
power to say enough: some of me stays, some of me stops.

`main.py` (Python 3.13, standard library only, no network) writes the fixed
poem. Deterministic: the same bytes on every run (268 characters).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
